# Поиск по кодовой базе

## 1. Определить инструмент поиска

- Найти что-то в маленькой локальной папке или в файле → можно использовать что угодно.
- Найти что-то по большой кодовой базе → использовать инструмент поиска `CODE_SEARCH_TOOL`.

Инструмент поиска хранится в `.claude/local/config.md` строкой `CODE_SEARCH_TOOL: <команда>`.

- `CODE_SEARCH_TOOL` задан → использовать его, у пользователя не спрашивать.
- Не задан, и ты субагент → не искать и инструмент самому не выбирать. Сразу вернуть основному агенту: «`CODE_SEARCH_TOOL` не задан, не знаю, чем искать». Основной агент выполнит шаги ниже и запустит поиск заново.
- Не задан, и ты основной агент → один раз:
  1. Проверить, какие инструменты есть в окружении: `which rg`, `git grep`, а также инструменты, которые упоминаются в README и документации проекта.
  2. Спросить пользователя, каким инструментом искать. Предложить найденные варианты.
  3. Записать ответ в `.claude/local/config.md` (создать файл, если его нет; остальные строки не трогать). Больше не спрашивать.

## 2. Справка по инструменту

Выжимка из `<команда> --help` хранится в `.claude/local/code-search-tool.md`.
Она нужна, чтобы агент знал, что можно использовать, а что нет.

Перед поиском прочитать `.claude/local/code-search-tool.md`.

- Файла нет, и ты субагент → не искать, вернуть основному агенту: «нет выжимки справки по инструменту». Файл с выжимкой пишет только основной агент.
- Файла нет, и ты основной агент → выполнить `<команда> --help` (и `--help` основных подкоманд, если они есть) и записать выжимку в `.claude/local/code-search-tool.md` (создать папку и файл, если их нет).
- Файл есть → работать по выжимке, `--help` заново не читать.
- `CODE_SEARCH_TOOL` изменился → написать выжимку заново.

Что должно быть в выжимке:
- команда и инструмент, для которого она написана;
- основные режимы поиска: точная строка, regex, по имени файла, по символу;
- как ограничить область поиска: папка, тип файла, язык;
- лимиты: число результатов, размер вывода;
- что инструмент не умеет или что использовать нельзя.

## 3. Разделить поиск на агентов

Разбить поиск на независимые части: по областям кода или по гипотезам.
Каждую часть отдать отдельному агенту `code-searcher` (`.claude/agents/code-searcher.md`). Агентов запускать параллельно.
Агент `code-searcher` получает этот скилл при старте. В задании указать только его часть поиска.

## 4. Куда сохранять

Куда сохранять, указывает тот, кто вызвал скилл (обычно это задание агента). Самому папку не выбирать.
Если в задании место не указано — ничего не сохранять, вернуть ответ.

## 5. Что должно быть в ответе

Ответ на заданный вопрос. Форму ответа выбирать под вопрос.
Утверждения о коде подкреплять ссылками `file:line`.
