# CLAUDE.md

## Настройки проекта

Настройки проекта (пути, параметры скиллов) хранятся в `.claude/config.md`, по одной строке `КЛЮЧ: значение`.
Скиллы читают их оттуда. Если нужного ключа нет — спросить пользователя один раз и дописать ключ в файл.

## Стиль написания

Стараться совпадать с форматом ASD-STE100 (Simplified Technical English).

Для русских текстов применять основные принципы этого стандарта:
- короткие предложения;
- одна мысль в предложении;
- активный залог;
- один термин для одного понятия.

## Параллельная работа

Перед началом работы понять, можно ли распараллелить действия.
Почти всегда нет смысла делать всё в одном агенте.
Пример: один агент делает ресерч, второй — аналитику, третий смотрит код.
Стараться максимально параллелить работу.
